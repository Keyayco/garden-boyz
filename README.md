# Garden Boyz — independent website demonstration

This is an unsolicited sales concept, not an official Garden Boyz website. Suggested services require business confirmation. All images are AI-generated inspiration, not completed projects. The enquiry form deliberately sends and stores nothing. No credentials, reviews, company history or email address have been invented.

## Run
Open index.html in a browser. This website uses only HTML, CSS and JavaScript; it needs no build step, libraries, account or paid API. The optional Manrope font loads from Google Fonts with a local sans-serif fallback.

## GitHub Pages
Copy this folder's contents to the root of a GitHub repository. In Settings → Pages, select Deploy from a branch, then choose the main branch and / (root). All website assets and links are relative, so repository subpaths work without configuration.

## Before business approval
Confirm actual services, wording and contact details. Replace demonstration images with approved business photographs if available. Remove the independent-demo notices only once the business approves an official site. Connect and test a secure enquiry endpoint before changing the form's explicit demo disclosure. Remove the noindex metadata only after approval to index the site.

## Files
- index.html: semantic page content and metadata
- styles.css: semantic colour tokens, layouts, accessibility and mobile presentation
- script.js: mobile navigation, service selection, image viewing and demo form
- images/: optimized local WebP images, including a smaller mobile cover
